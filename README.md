# Vipul Portfolio

This repository contains my personal portfolio website, designed to highlight my professional journey as a **Software Developer (.NET & API Specialist)** and immediate joiner.

## 🚀 Features
- Responsive design with clean layout
- Sections: About Me, Experience, Education, Skills, Projects, Contact
- Downloadable resume
- Styled with CSS, dynamic content via JavaScript
- Easy navigation with mobile‑friendly menu

## 🛠️ Tech Stack
- HTML5
- CSS3
- JavaScript (data.js + script.js)
